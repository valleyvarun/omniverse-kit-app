Drawing Intelligence

Sketch in 3D with a pen or mouse. Built on NVIDIA Omniverse Kit.

Download for Windows

Windows 10 or 11, 64-bit · Free

The installer runs on Windows only for now. Open this page on a Windows PC to install Drawing Intelligence.

Install in four steps

  1. Run the installer. Windows may show “Windows protected your PC” because the installer isn’t code-signed yet. Select More info, then Run anyway.
  2. Accept NVIDIA’s license terms. Drawing Intelligence runs on the NVIDIA Omniverse Kit SDK, which the installer downloads from NVIDIA.
  3. Choose a folder and wait. The first install needs about 4 GB of disk space and takes roughly 10–30 minutes, depending on your connection. You don’t need administrator rights.
  4. Open Drawing Intelligence. Use the shortcut on your desktop or in the Start menu. The installer names it 3D Drawing (WIP).

What the installer does

  • Downloads NVIDIA’s Kit App Template (version 109.0.3).
  • Replaces the template’s source folder with the app’s code from this GitHub repository.
  • Builds the app, which downloads the Kit SDK and extensions.
  • Adds a desktop shortcut and a Start menu entry.

The app goes in %LOCALAPPDATA%\Programs\3D-Drawing, or in C:\3D-Drawing if your Windows user folder has a space in its name. You can choose another folder, but its path can’t contain spaces because the Kit build tools don’t support them.

Requirements

  • Windows 10 or 11, 64-bit
  • A graphics card with current drivers (an NVIDIA RTX GPU is recommended)
  • About 4 GB of free disk space
  • An internet connection during installation

Update or uninstall

To update, download and run the installer again. It replaces your installation with the latest version.

To uninstall, open Settings > Apps > Installed apps, find 3D Drawing (WIP), and select Uninstall. Kit keeps shared downloads in C:\packman-repo and %LOCALAPPDATA%\ov for other Kit apps. You can delete those folders if no other Kit app uses them.
